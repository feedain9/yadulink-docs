# Import from your Yadulink contacts

Use the contacts already known by Yadulink to build a focused list from your outreach and LinkedIn relationship history.

## Open the contact selector

1. Open **Contact lists** and select the destination list.
2. Open the **Add contacts** tab.
3. In **From my Yadulink contacts**, select **Choose contacts**.
4. Select one or more signals, then use **Show preview** before importing.
5. Select **Import the contacts** when the selection is ready.

You can combine several signals in one import. If a contact matches more than one selected signal, Yadulink adds that contact to the destination list only once.

:::info LinkedIn network sync
The three network-based signals become available after Yadulink has prepared your LinkedIn network. The selector displays the current synchronization status. You can still use the reply-based signals while the network is being prepared.
:::

## Signal overview

| Signal | Contacts included |
| --- | --- |
| **I contacted them, but they haven't replied** | Contacts you messaged from Yadulink who have not sent an incoming message or reaction since. |
| **They have already replied** | Contacts for whom Yadulink knows of at least one incoming message or reaction. |
| **My entire LinkedIn network** | All first-degree LinkedIn connections in the selected destination list. |
| **In my network, never contacted** | First-degree connections with no incoming or outgoing message known by Yadulink. |
| **New connections without a first message** | Accepted invitations for which Yadulink does not yet know of a first message. |

## I contacted them, but they haven't replied

Choose this signal to find contacts you have messaged from Yadulink without receiving a message or reaction from them afterwards.

When you select it, use **No reply for at least** to set the minimum number of days without a reply. The interface starts at 30 days; adjust the value to match the follow-up window you want to review.

![The “I contacted them, but they haven't replied” signal selected in Yadulink](/img/liste-de-contacts/signal-contacted-no-reply.jpg)

## They have already replied

Choose this signal for contacts with at least one incoming message or reaction known by Yadulink. It is useful when you want a list based on an existing interaction rather than unanswered outreach.

![The “They have already replied” signal selected in Yadulink](/img/liste-de-contacts/signal-already-replied.jpg)

## My entire LinkedIn network

Choose this signal to add all first-degree LinkedIn connections directly to the selected destination list. Yadulink does not create an intermediate network list.

![The “My entire LinkedIn network” signal selected in Yadulink](/img/liste-de-contacts/signal-entire-linkedin-network.jpg)

## In my network, never contacted

Choose this signal for first-degree connections with no incoming or outgoing message known by Yadulink. “Never contacted” therefore refers to the conversation history available to Yadulink.

![The “In my network, never contacted” signal selected in Yadulink](/img/liste-de-contacts/signal-never-contacted.jpg)

## New connections without a first message

Choose this signal for accepted LinkedIn invitations where Yadulink does not yet know of a first message. This lets you isolate new relationships that have not started a conversation yet.

![The “New connections without a first message” signal selected in Yadulink](/img/liste-de-contacts/signal-new-connections-no-message.jpg)

:::note
This flow only adds matching contacts to the destination list. It does not send a LinkedIn message or start a sequence.
:::
